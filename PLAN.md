# AI Scout: План реализации (Reboot)

## Стек технологий
- **Framework**: Next.js 15 (App Router)
- **Database/Auth**: Firebase (Firestore, Auth)
- **AI**: Google Gemini (через прямой API fetch)
- **Styling**: Vanilla CSS + Tailwind (если потребуется)
- **Icons**: Lucide React

## Этапы реализации

### Этап 1: Фундамент и Очистка
- [ ] Создать `PLAN.md` (Выполнено)
- [ ] Очистить `src/app/page.tsx` и создать базовую структуру компонентов.
- [ ] Настроить глобальные стили в `src/app/globals.css` (Premium Dark Mode).
- [ ] Убедиться, что `src/lib/firebase/firebase.ts` работает корректно.

### Этап 2: AI Слой (Gemini)
- [ ] Доработать `src/lib/ai/gemini.ts` для поддержки JSON-анализа.
- [ ] Реализовать промпты для анализа YouTube видео и Telegram постов.
- [ ] Создать логику детекции упомянутых инструментов/сервисов.

### Этап 3: Источники данных
- [ ] Реализовать `src/lib/sources/youtube.ts` (базовый парсинг метаданных).
- [ ] Реализовать `src/lib/sources/telegram.ts` (заглушка или парсинг через API).
- [ ] Создать `src/lib/sources/processor.ts` для объединения AI и парсинга.

### Этап 4: Интерфейс (UI)
- [ ] **Главная лента (Feed)**: Карточки новостей с AI-выжимкой.
- [ ] **Умный поиск (AI Insight)**: Поисковая строка с мгновенным ответом от Gemini.
- [ ] **Архив инструментов**: Сетка инструментов с фильтрами по категориям.
- [ ] **Добавление ресурсов**: Простая форма для вставки URL.

### Этап 5: Деплой и Проверка
- [ ] Запуск `npm run pre-deploy`.
- [ ] Деплой на Vercel.

## Структура данных (Firestore)
- `sources`: Коллекция отслеживаемых каналов/групп.
- `posts`: Коллекция проанализированных новостей.
- `apps`: Коллекция найденных инструментов (Архив).
- `favorites`: Избранное пользователя.
